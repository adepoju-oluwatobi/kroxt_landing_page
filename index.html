The Headless
Auth Engine.

A framework-agnostic, modular authentication engine for modern TypeScript applications. Stay in control of your data and your UI.

Get Started
$ npm i kroxt

How it Works.

1

Define your User

Start by defining what your user looks like. Kroxt is fully extensible—add roles, school IDs, or metadata with full type safety. 

interface MyUser {
  id: string;
  email: string;
  role: 'admin' | 'user';
  schoolId: string;
}
import { createMongoAdapter } 
  from "kroxt/adapters/mongoose";

// Connect to MongoDB in one line
const adapter = createMongoAdapter(User);
2

Choose an Adapter

Use built-in adapters for MongoDB (Mongoose) or In-Memory storage. More official adapters (Prisma, Drizzle) are coming soon, or you can implement your own custom one.

3

Hook it Up

Initialize the engine with your adapter. Use the jwt.payload hook to sign custom user data into your tokens. 

export const auth = createAuth({
  adapter,
  jwt: {
    payload: (user, type) => ({
      schoolId: user.schoolId
    })
  }
});
const { accessToken } = await auth.signup(data, pwd);
const payload = await auth.verifyToken(token);
4

Ship with Confidence

Use robust methods for signup, login, token rotation, and verification. Kroxt handles hashing, salts, and JWT security for you.

Built-in Security.

Argon2 + Pepper

Industry leading hashing with hardware-locked pepper support.

Timing Attack Protection

Constant-time comparisons and simulated delays for failed logins.

Token Rotation

Automatic refresh token rotation to prevent replay attacks.

Zod Validation

Type-safe configuration and user data validation out of the box.

Custom JWT Payloads

Sign custom user details into the token without losing type safety.

Built-in Adapters

One-line integration for MongoDB (Mongoose) and In-Memory storage.

Dual ESM/CJS Support

Native support for both modern ESM and traditional CommonJS projects.
