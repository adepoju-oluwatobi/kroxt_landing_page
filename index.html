The Headless
Auth Engine.

A framework-agnostic, modular authentication engine for modern TypeScript applications. Stay in control of your data and your UI.

Get Started
$ npm i kroxt

Framework Agnostic

Kroxt doesn't care if you use Express, Next.js, Fastify, or Hono. It provides the core logic, you decide the transport.

Modular Adapters

Bring your own database. Implement a simple interface and Kroxt handles the rest. Support for Prisma, Mongoose, Drizzle, and more.

auth.ts 
export const auth = createAuth({
  adapter: mongoAdapter,
  secret: process.env.JWT_SECRET,
  session: {
    expires: "15m",
    refreshExpires: "7d"
  }
});

Built-in Security.

Argon2 + Pepper

Industry leading hashing with hardware-locked pepper support.

Timing Attack Protection

Constant-time comparisons and simulated delays for failed logins.

Token Rotation

Automatic refresh token rotation to prevent replay attacks.

Zod Validation

Type-safe configuration and user data validation out of the box.
