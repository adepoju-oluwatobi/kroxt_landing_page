Documentation

Master Kroxt Auth in a few simple steps.

1

Installation

Kroxt is a lightweight, headless engine with zero unnecessary dependencies. Start by installing the core package.

$ npm i kroxt
2

Configuration

Initialize the engine with your adapter, secrets, and session preferences.

lib/auth.ts
import { createAuth } from "kroxt";
import { mongoAdapter } from "./adapter.ts";

export const auth = createAuth({
  adapter: mongoAdapter,
  secret: process.env.JWT_SECRET,
  pepper: process.env.JWT_PEPPER,
  session: {
    expires: "15m",
    refreshExpires: "7d"
  }
});
3

Auth Flows

Use the auth object to handle registrations, logins, and token rotations effortlessly.

Signup

auth.signup(data, pwd)

Login

auth.loginWithPassword(e, p)
4

The Adapter Pattern

Kroxt is database-independent. To support any database, simply implement the AuthAdapter interface.

interface
export interface AuthAdapter {
  createUser: (data: any) => Promise<User>;
  findUserByEmail: ...;
  findUserById: ...;
}
