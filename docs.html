Documentation

Master Kroxt Auth in a few simple steps.

$ npm i kroxt
1

Define your User

Start by deciding what data you want to store for your users. Kroxt is flexible—you can add any fields like role or schoolId.

types.ts
export interface MyUser {
  id: string;
  email: string;
  passwordHash: string;
  role: 'admin' | 'user';
  schoolId: string;
  oauthProvider?: string; // Support for OAuth
  oauthId?: string;       // ID from provider
}
2

Create the Adapter

The Adapter is like a translator. It tells Kroxt how to talk to your specific database. Here is a complete Mongoose implementation:

lib/adapter.ts
import type { AuthAdapter } from "kroxt/adapter";
import { User } from "../models/user.model.js";

export const myAdapter: AuthAdapter<MyUser> = {
  createUser: async (data) => {
    const user = await User.create(data);
    const obj = user.toObject();
    return { ...obj, id: obj._id.toString() };
  },
  findUserByEmail: async (email) => {
    const user = await User.findOne({ email });
    if (!user) return null;
    const obj = user.toObject();
    return { ...obj, id: obj._id.toString() };
  },
  findUserById: async (id) => {
    const user = await User.findById(id);
    if (!user) return null;
    const obj = user.toObject();
    return { ...obj, id: obj._id.toString() };
  },
  linkOAuthAccount: async (id, provider, providerId) => {
    await User.findByIdAndUpdate(id, {
      oauthProvider: provider,
      oauthId: providerId
    });
  }
};
3

Initialize the Engine

Now, hook up your adapter and set your security keys. This creates the auth object you'll use everywhere.

lib/auth.ts
import { createAuth } from "kroxt";

export const auth = createAuth({
  adapter: myAdapter,
  secret: process.env.JWT_SECRET,
  jwt: {
    payload: (user, type) => {
      // Sign custom details into the JWT!
      if (type === "access") {
        return { schoolId: user.schoolId, role: user.role };
      }
      return {};
    }
  }
});
4

Use the Auth Flows

Kroxt provides a set of powerful methods to handle every part of your authentication lifecycle.

1. Registration & Login

// Register a new user
const { user, accessToken } = await auth.signup(userData, password);

// Login an existing user
const { accessToken, refreshToken } = await auth.loginWithPassword(email, password);

2. Protecting Routes (Middleware)

Use verifyToken to protect your private API endpoints.

const protect = async (req, res, next) => {
  const token = req.headers.authorization?.split(" ")[1];
  const payload = await auth.verifyToken(token, "access");
  
  if (!payload) return res.status(401).json({ error: "Unauthorized" });
  
  req.user = payload; // Contains sub, role, schoolId, etc.
  next();
};

3. Token Rotation (Refresh)

Keep users logged in securely by rotating tokens.

const { accessToken } = await auth.refresh(refreshToken);
